# Research Atlas

**[Каталог и архив](https://nziben.github.io/research-atlas/)**

Два самостоятельных сайта и репозитория:

- [Человек и ИИ](https://nziben.github.io/human-agency-review/) · [репозиторий](https://github.com/nZiben/human-agency-review).
- [Общая память агентов](https://nziben.github.io/shared-agent-memory-review/) · [репозиторий](https://github.com/nZiben/shared-agent-memory-review).

В каждом — краткий ответ, карта вопроса, сравнение методов, ограничения и следующая проверяемая гипотеза. По 50 публикаций в каждом: выводы связаны с выбранными абзацами конкретных версий. В таблицах можно искать работы и выбирать подтему; тип исследования указан отдельно. Это не исчерпывающие обзоры. Эксперименты не воспроизводились, независимой рецензии нет. Десять прежних обзоров доступны в архиве.

Этот репозиторий хранит каталог, архив и общие инструменты. Основные темы развиваются в отдельных репозиториях. Сайты статические и только для чтения. По понедельникам GitHub Actions ищет новые arXiv-кандидаты по сохранённым запросам. Два новых фокуса включены в следующие запуски; разовая расширенная подборка опубликована отдельно от автоматической очереди. Поиск не переписывает научные выводы, модельная генерация требует отдельной настройки.

```bash
python3 -m review_forge build-site --library library --destination public
python3 -m review_forge serve --open
```

Python 3.11+. [Подход и источники дизайна](docs/focused-reader.md) · [Настройка](docs/local-setup.md) · [Публикация](docs/publication.md)
