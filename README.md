# Research Atlas

Библиотека исследований AI: safety, интерпретируемость, эффективность, NLP, агенты, vision, robotics, RL, оценка и AI for Science.

**[Открыть сайт](https://nziben.github.io/research-atlas/)**

Опубликованы **10 концептуальных обзоров** по узким вопросам десяти направлений: краткое объяснение, подробный разбор, таблица условий и доказательства. В обзорах — 73 разобранные работы; их эксперименты мы не воспроизводили. Дополнительная библиография пополняется автоматически; её объём и дата последней проверки видны на сайте.

[Родственные проекты и ограничения](https://nziben.github.io/research-atlas/related.html).

Сайт статический, только для чтения. GitHub Actions проверяет новые статьи и версии по понедельникам в 02:17 UTC и публикует кандидатов автоматически. Выводы обзоров обновляются после разбора источников. Ключи модели для поиска не нужны; приватные материалы на сайт не попадают.

```bash
python3 -m review_forge serve --open
```

Для локального конвейера нужны Python 3.11+ и PDF-зависимость: `python3 -m pip install -e '.[pdf]'`.
