## Как собирался корпус

В `search-plan.json` зафиксированы вопросы, запросы, диапазон дат, сортировки, объём выдачи и тематические фильтры. Для каждой темы выполняются четыре стратегии: релевантность (до 60 записей), свежие публикации (50), ранние работы (100), оценка/ограничения (40). Ранее найденные 40 записей сохранены как явные seeds. Это **не квота включённых работ**: сохраняются все подходящие возвращённые записи после фильтрации и дедупликации.

Поисковая выдача дополнительно проверяется по явным выражениям в названии и аннотации. Это предварительный технический отбор, который может ошибаться. В частности, `speculative samples` не считается speculative decoding, а `reasonable` — reasoning. Научная значимость, отрицательный результат или надёжность эксперимента не определяются такими словами.

Метаданные получены из arXiv Atom API. В `papers.json` сохранены версии, авторы, DOI при наличии, даты, группы обнаружения, URL запросов, объёмы выдачи, усечение и SHA-256 ответов. Отсеянные по тематическим выражениям ID сохранены в журнале. Дубликаты удалены по arXiv ID, точному нормализованному названию или DOI; не применяется нечёткое угадывание идентичности работ.

## Как повторить

```bash
python3 -m review_forge.bibliography --checked-at 2026-11-08
python3 -m review_forge build-site --library library --destination public
```

Первая команда делает только поисковые GET-запросы. Кеш и сырой XML остаются в игнорируемой `library/.bibliography-search/`. При ошибке предыдущий `papers.json` сохраняется. Перед новым поиском пересмотрите `through` в плане и дату проверки. Модели не вызываются, публикация выполняется отдельно.

## Ограничения

Выдача усечена: в каждой теме существуют дополнительные совпадения. Это не полный systematic review. Работа может быть важной и не пройти словарный фильтр; попадание в корпус тоже не гарантирует релевантность. Часть ранних работ служит историческим контекстом, а не прямым ответом на текущий вопрос.

Источник обнаружения — arXiv. Публикации, доступные только через конференционные архивы и другие базы, могут отсутствовать. Препринт не считается прошедшим рецензирование без отдельной проверки. Дата поиска не гарантирует отсутствие более свежих неиндексированных работ.

Полные тексты, эксперименты и выводы **не разобраны**. Статус `metadata_only` сохраняется на сайте; цитат, модельных выводов и имитации научной проверки нет. Для содержательного обзора нужны отбор по вопросам, чтение полных текстов, матрица свидетельств и разбор противоречий. Требования — в [стандарте комплексного обзора](../docs/comprehensive-reviews.md).
