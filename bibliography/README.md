# Библиография

Поиск: **8 ноября 2026**, по десяти узким вопросам из `review_forge/topics.json`. Начальная подборка включает 40 работ; более ранние статьи оставлены как контекст для новых публикаций. Это ограниченный поиск, не полный перечень литературы и не рейтинг работ.

Названия, авторы, даты, версии и DOI в `papers.json` получены из реальных записей arXiv Atom API. Ссылка на запрос и SHA-256 ответа сохранены в файле. Статья могла обновляться после первой подачи: `published_at` и `updated_at` показываются отдельно. Препринт не считается рецензированной публикацией без отдельной проверки.

Проверялись библиографические записи и соответствие темам по названиям/аннотациям. Полные тексты и экспериментальные выводы не проходили научную проверку; LLM-обзоры не генерировались. Статус `metadata_only` сохраняется на сайте. Ссылки ведут на конкретную проверенную версию.

Начальная подборка хранится отдельно от источников выпущенных обзоров. Добавление статьи в этот файл не объявляет её доказательством какого-либо вывода. Полные тексты, PDF и переводы в публичный репозиторий не включены.

Для продолжения поиска используйте приватный `maintain`; для изменения публичной подборки — проверенные записи в `papers.json` и новую сборку сайта. Детали публикации — в [инструкции](../docs/publication.md).
