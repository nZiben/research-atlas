# Проверки перед публикацией

8 ноября 2026, Python 3.13.5, macOS.

- 47 локальных тестов прошли: инварианты конвейера, отсутствие публичных API записи, границы приватных файлов, сохранность предыдущей сборки, мониторинг и отображение библиографии без фиктивного обзора.
- Выполнены Python compilation, JavaScript syntax check и статическая сборка `public/`.
- Выполнены четыре реальные поисковые стратегии по каждой из десяти тем. Проверены даты, ID, предварительные тематические фильтры и дедупликация. URL запросов, счётчики и хеши ответов есть в `bibliography/papers.json`. Добавлены регрессии против нерелевантных текстовых совпадений.
- Сайт проверен в браузере: темы, источники, ссылки на версии arXiv и фильтрация. Статический хостинг не вызывает модели и не хранит ключи.

Реальные модельные вызовы, полный разбор корпуса и успешный сквозной выпуск концептуального обзора не выполнялись. Библиография не выдаётся за завершённый научный обзор или полный охват литературы. Поиск не установлен как фоновая служба.

Workflow GitHub Pages публикует только `public/`; статус конкретного развёртывания хранится в Actions и Pages репозитория.


## Первый концептуальный выпуск — 13 ноября 2026

53 теста прошли, включая 6 проверок редакционной публикации: ссылки на реальные тезисы, версии первоисточников, бюджет цитат, запрет приватных полей и сохранность прежнего сайта при ошибке. Проверены compileall и синтаксис JavaScript.

Первый обзор основан на указанных разделах 10 полных HTML-текстов arXiv. Сверены короткие цитаты и source SHA-256; все численные результаты приписаны авторам. Собственные эксперименты, независимая научная рецензия и живой API-конвейер не выполнялись.

В локальном браузере проверены краткий/подробный режим, 10 строк сравнительной таблицы, переход от вывода к раскрытой цитате и ссылке на точную версию источника, дерево подтем и страница родственных проектов. На мобильной ширине 390 px страница не переполняется; широкая таблица прокручивается внутри контейнера.


## Все направления и автоматическое discovery — 13 ноября 2026

Опубликованы 10 узко сфокусированных обзоров: 73 выбранные работы суммарно. Для новых девяти обзоров получены полные HTML и метаданные точных версий 63 работ. Цитаты, локаторы и SHA-256 сверены локально. Один первоначально выбранный HTML был недоступен и заменён другим проверенным источником; недоступный текст не выдавался за прочитанный.

Реальная incremental-проверка arXiv прошла все 10 тем: добавлены 326 записей по темам и обнаружена 21 новая версия. Уникальный поисковый корпус — 1982 публикации. Сырые ответы сохранены приватно; повторный прогон по кешу сохранил накопленные записи. Результаты поиска являются кандидатами с проверенными метаданными, а не свидетельством их релевантности каждому выводу обзора.

61 тест прошёл, включая инварианты накопительного merge, сохранность исходных данных при сетевом сбое, rejection не-Atom ответа, даты верификации и наличие обзора/дерева во всех направлениях. compileall и проверка синтаксиса JavaScript прошли. В браузере просмотрены все 10 обзоров и таблиц (73 строки суммарно), проверены desktop и ширина 390 px без переполнения страницы, а также отображение последнего discovery и даты добавления кандидатов. Ошибок консоли не обнаружено.

Собственные ML/robotics эксперименты, независимая экспертная рецензия и полный платный API-конвейер не запускались. Scheduled workflow выполняет только поиск кандидатов и публикацию статических файлов. Его реальные сетевые/публикационные запуски проверяются через GitHub Actions; наличие YAML само по себе не подтверждает успешный запуск.

Реальный GitHub Actions запуск [43386505678](https://github.com/nZiben/research-atlas/actions/runs/43386505678) успешно выполнил discovery по всем десяти темам, 61 тест до и после поиска, автоматический commit и reusable Pages deploy. Последующая локальная проверка защиты от укороченной промежуточной страницы расширила набор до 62 тестов. Эта защита останавливает поиск до публикации, если продолжение выдачи могло бы быть пропущено.
